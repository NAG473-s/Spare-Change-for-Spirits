# Legacy 2D images

Images from the 2D version of the shop: furniture and keepsakes (`decor/`) and the door, counter
and back-wall background (`shop/`). Since the switch to the 3D diorama these are 3D models
(`assets/models/`), so the game no longer loads these files. They are kept here, outside the
packaged `assets/`, for reference and promotional use.
